Chunking & indexing

  • Chunks: usually ≤ a few hundred tokens; size, boundary, overlap are tunables → run evals. CR
  • Structure-aware splits (sections, intact tables) + metadata (source, revision, page, date). Architect practice
  • Contextual Retrieval: Claude writes 50–100 tokens of doc context per chunk, prepended before embedding and BM25. ≈ $1.02 / M doc tokens with caching. CR
  • Alternative: contextualized chunk embeddings (voyage-context-4): doc context per chunk, no LLM step. Embeddings; voyage-context-4
  • Anthropic has no embedding model; docs point to Voyage AI (MongoDB), assess vendors. Set input_type query/document. Embeddings
  • Voyage now: voyage-4-large/4/4-lite, voyage-code-4, voyage-law-2, voyage-finance-2, voyage-multimodal-3.5, voyage-context-4; rerankers rerank-3, rerank-3-lite (drop-in, 2.5 thresholds still valid). Embeddings; Rerank 3
  • Same vector space for queries and index. The 4 general Voyage 4 models (large/base/lite/nano) share one space (swap query model "without re-vectorizing documents"); any other model change = re-embed corpus. Voyage 4
  • Doc refresh broke answers? Check the indexing path (embedding model, chunker, contextualizer) before the model. Blueprint heuristics

Grounding & citations

  • 20k+ tokens: long docs at the top, query at the end (up to 30% better); <document>/<source> XML; quote first, then answer. Prompting best practices
  • Citations (all active models): document blocks (text/PDF sentence-chunked; custom content as-is; inline or Files API file_id) or search_result blocks (tool result or top-level). Valid pointers guaranteed; cited_text not billed as output. Citations; Search results
  • Works with caching, batch, token counting. Not with structured outputs (400). Citations

Observability

Multi-agent research system (June 2025); OTel GenAI semconv; Usage and Cost API

  • Agents: non-deterministic even with identical prompts; stateful, errors compound → full production tracing, resume from failure point.
  • Rainbow deployments: shift traffic gradually, old and new running together, so in-flight agents survive.
  • Privacy: monitor decision patterns and interaction structure, not conversation contents.
  • OTel GenAI (status Development): spans for inference, embeddings, retrieval, memory ops, invoke_agent, execute_tool; metrics gen_ai.client.inference.duration, gen_ai.client.inference.time_to_first_chunk, gen_ai.server.time_to_first_token, gen_ai.execute_tool.duration, gen_ai.client.inference.usage.* (input, output, cache_read, cache_write, reasoning). gen_ai.client.operation.duration = non-inference ops only.
  • Usage & Cost Admin API (Admin key): usage_report/messages tokens by model/workspace/API key/service tier, 1m–1d buckets; cost_report daily USD; data ≈ 5 min fresh. Claude Code per-user: Claude Code Analytics API.
  • Content (instructions, inputs, outputs): SHOULD NOT capture by default; opt-in. Production: store externally with separate access control, reference from spans.
  • Watch: p50/p95 latency, TTFT, tokens + cache hits, cost/request, error and tool-failure (is_error) rates, retrieval hit rate, quality drift (LLM-as-judge + human sample).
