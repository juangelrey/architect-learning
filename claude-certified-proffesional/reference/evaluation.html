Evaluation, testing & optimization

Measure first, change one thing, prove it with error bars, then optimise. Demystifying evals for AI agents

Success criteria

Define success criteria and build evaluations

  • Specific · measurable · achievable · relevant. Multidimensional: fidelity, consistency, relevance, tone, privacy, context use, latency, price.
  • Bad: "safe outputs". Good: "< 0.1% of 10,000 outputs flagged for toxicity". Example set: F1 ≥ 0.85 · 99.5% non-toxic · 95% < 200 ms.

Eval design & graders

Develop tests; Demystifying evals

  • Task-specific (real distribution + edge cases) · automate · volume over quality.
  • Edge cases: irrelevant/missing input, overly long input, harmful input, ambiguous cases.
  • Sources: golden set (reference answers) · edge cases · production failures (start with 20–50) · balanced should/shouldn't cases.

pass^kAll k succeed; falls with k (0.75³ ≈ 42%). Customer-facing consistency.

Iterate & compare

  • Swiss cheese: automated evals (every commit, may mislead) · A/B (real outcomes, days–weeks) · monitoring (ground truth, reactive) · user feedback (sparse) · transcript review (doesn't scale). Demystifying evals
  • Offline before online; shadow on a traffic slice before cutover, keep the suite running (cost guide); rainbow deployments for long-running agents (multi-agent post); one change at a time (general practice).
  • Stats: report SEM (95% CI ≈ ±1.96 SEM) · cluster SEs for grouped questions (can be > 3×) · resample per question · paired differences for A vs B · power analysis to size the eval. Statistical approach to model evals
  • Infra noise: resource settings moved Terminal-Bench 2.0 by 6 pts; distrust gaps < 3 pts until configs match. Infrastructure noise

Optimize (as of Oct 2026)

Free wins (no quality cost): caching · token trimming · batch · prompt audit · workspace spend limits. Trade-offs: model · effort · output caps / task budgets · multi-model. Caching = biggest lever (agent loops 2.7–5.3× cheaper). Compare models on cost per completed task, not per token. Optimizing for cost and intelligence
