Sandbox

Shell commands (Bash, PowerShell, Monitor); Seatbelt (macOS), bubblewrap (Linux/WSL2), none on native Windows; off by default. Writes: cwd + temp. Network: proxy, empty allowlist. Outside it: Read/Edit/Write/WebFetch tools, hooks, local MCP servers. Enforce: {"sandbox":{"enabled":true,"failIfUnavailable":true,"allowUnsandboxedCommands":false}}. TLS not inspected by default. Workflow and debugging

  • Explore → Plan (plan mode) → Implement → Commit; always give a way to verify.
  • /clear between tasks and after two failed corrections; /compact <focus>; subagents for exploration.
  • Parallel: worktrees (claude -w name, .worktreeinclude), /batch, background sessions (claude --bg, claude agents), agent teams (experimental, off by default). /rewind for checkpoints (Bash changes not tracked).
  • /doctor (in-session fixes) · claude doctor (read-only, when it won't start) · /debug · /status · /context · /hooks · /mcp · claude --debug=mcp · claude --safe-mode · clean test claude --setting-sources user.
  • Classic bugs: .mcp.json in .claude/; mcpServers in settings.json; relative MCP paths; matcher bash; skill not in a folder.
