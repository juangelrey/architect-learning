Effort & thinking

Effort · Thinking · Task budgets

Effortoutput_config.effort: low · medium · high · xhigh · max. Affects thinking, tool calls and text. Behavioural signal, not a budget; max_tokens is the hard cap. Tune effort before switching model.
Cache impactChanging top-level effort breaks the cache. Per-message effort (beta; Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5) keeps it.
Task budgetBeta. output_config.task_budget: advisory token total for a whole agent loop (min 20k). Effort = depth, budget = breadth; max_tokens still the hard cap.
Adaptive thinkingClaude decides when and how much to think. Always on for Fable 5.1 and Opus 5.5 (disabled → 400). Haiku 5.5: can disable at ≤ high. Sonnet 5.5: lowest is between_tools.
Extended thinkingenabled + budget_tokens: deprecated on 4.6, 400 error on 4.7+.
BillingThinking billed as output even when hidden (display: "omitted" default on new models). Prior turns' thinking is kept in context on current models (counts toward window, billed as input).

Prompting best practices · Reduce hallucinations · Structured outputs

Clarity"Brilliant but new employee." Explain why. One-line role in the system prompt.

Long context20k+ tokens: documents at top, query last (up to 30% better).
Few-shot3–5 relevant, diverse examples in <example> tags. Canonical, not a laundry list of edge cases.
CoTUse thinking + effort. "Think thoroughly" beats prescriptive steps. Manual CoT with <answer> only when thinking is off. On Fable 5.1, Opus 5.5 and Sonnet 5.5, asking for written <thinking> may be declined.
PrefillUnsupported from 4.6 (400). Format → structured outputs / strict tools; classify → enum tool or structured outputs; preamble → instruction.

Structured outputsGA. output_config.format JSON schema or strict: true tools. Constrained decoding = always valid (except refusals / max_tokens cut-off). No recursive schemas, numeric/length constraints, or additionalProperties ≠ false. First-use compile latency; grammar cached 24 h from last use.
GuardrailsAllow "I don't know" · quote first · cite or retract · only provided docs · best-of-N.
ChainingStill useful to inspect intermediate outputs (draft → review → refine).

Context management

Context windows · Compaction · Context editing · Token counting · Context engineering

  • Context rot: accuracy and recall degrade as tokens grow. Aim for the smallest high-signal set; retrieve just-in-time.
  • Compaction (beta): server-side summary of older turns; on demand (recommended, compact-2026-09-04) or at a token threshold. Primary strategy.
  • Tool-result clearing (context editing, beta): trigger default 100k input tokens, keep 3, clear_at_least (clearing breaks the cache), exclude_tools. Thinking-block clearing for old thinking (current models keep all by default).
  • Memory tool (memory_20250818, all Claude 4+ models): client-side /memories files you store; persists across sessions. Pair with clearing/compaction. Validate paths (traversal). Memory tool
  • Many tools? Defer definitions with the tool search tool instead of loading every schema. Tool search tool
  • Token counting: free, separate RPM limit, estimate only, no caching. Opus 4.7+ tokenizer ≈ +30% tokens: recount.
  • Cached tokens still fill the window. Prompt too long → 400; output hits the limit → model_context_window_exceeded.

Prompt caching

Prompt caching

Ordertools → system → messages. Stable first, volatile last.
Breakpoints≤ 4 explicit; automatic (top-level cache_control) takes one slot; 20-position lookback.
TTL5 min (refreshed on hit) · 1 h ("ttl": "1h").
PriceWrite 1.25× / 2× · read 0.1× (0.05× Opus 5.5 & Sonnet 5.5; 0.025× Fable 5.1). Break-even: 1 read (5 min), 2 reads (1 h).
Min length512 tokens (5.5 models, Fable 5.1); 1,024–4,096 older. Shorter = silently uncached.
Breaks itTool change → all · web search/citations/speed toggle → system + messages · images, tool_choice, thinking/effort → messages.
Keep itChange instructions with a mid-conversation {"role": "system"} message, not by editing system. Keep history append-only. Mid-conversation system messages
DebugCache diagnostics (GA, Claude API): diagnostics.previous_message_id → first divergence (system_changed, tools_changed, messages_changed, model_changed). Cache diagnostics
Pre-warmmax_tokens: 0 writes the cache with no output (not in batches or streams).
