Domains & task statements

D1 · 17% Solution Design & Architecture

  • Translate business problems into Claude-based AI solutions
  • Design end-to-end architectures (input → processing → output → feedback loops)
  • Select architectural patterns (workflow, agentic, augmented LLM)
  • Design multi-agent systems and orchestration strategies
  • Apply decomposition techniques
  • Align to business value pillars (efficiency, transformation, productivity, cost, performance SLAs)

D2 · 13% Claude Models, Prompting & Context Engineering

  • Select Claude models based on trade-offs
  • Design system prompts, templates, guardrails
  • Apply zero-shot, few-shot, chain-of-thought
  • Optimize context windows and token usage
  • Prompt reuse (caching, modular prompts, Skills)

D3 · 19% Integration

  • Evaluate tool/agent configuration for capability bloat
  • Analyze authN/authZ requirements for security gaps
  • Evaluate accuracy–latency trade-offs
  • Observability challenges and monitoring at scale
  • RAG pipeline: chunking and indexing
  • Retrieval strategies matched to data shape and query pattern
  • Select integration mechanism (MCP, API/CLI, agent-to-agent)
  • Progressive discovery vs monolithic context

D4 · 16% Evaluation, Testing & Optimization

  • Metrics (accuracy, latency, cost, safety, security)
  • Eval datasets and test frameworks, mixed methods
  • A/B testing and iteration
  • Diagnose issues (prompt failure, hallucination, model mismatch)
  • Optimize token use, latency, cost–performance
  • Monitor with logging and observability tools

D5 · 14% Governance, Safety & Risk Management

  • Guardrails and safety controls
  • Risks, limitations, failure modes of LLM systems
  • Human-in-the-loop validation
  • Compliance (GDPR, HIPAA, FedRAMP)
  • Ethics (bias, fairness, transparency)

D6 · 14% Stakeholder Communication & Lifecycle

  • Structured discovery and requirements
  • Communicate decisions and trade-offs
  • Stakeholder feedback loops, expectations, SLAs
  • Document architectures, implementation guidance
  • Lifecycle: discovery → design → handoff → monitoring → iteration

D7 · 7% Developer Productivity & Operational Enablement

  • Configure Claude tools/environments for teams (e.g. Claude Code)
  • Improve developer workflows with AI tooling
  • Support debugging and operational issue resolution

Answer heuristics from the official samples

  • Remove, don't monitor: least privilege = drop unneeded tools, not log or confirm them.
  • Static first, then cache: stable prompt prefix + prompt caching cuts both cost and latency.
  • Diagnose what changed: a symptom after a doc refresh → retrieval/indexing first, not the model.
  • "Bigger model" is rarely the fix for a security or retrieval problem.
